Šio projekto turinys parengtas Jono Geglio mokymosi tikslais pagal VU MIF infromatikos "Optimizavimo metodai" modulio lūkesčius.

Projekto turinys- projektas sudarytas iš 5 klasių:

Main- kviečia kitų klasių metodus, kad pademonstruoti algoritmų veikimus.

Function- atsakinga už, išvedimą minimumo, iteracijų ir funkcijos kvietimų, funkcijos atvaizdavimą, funkcijos aprašą, saugojimą pagrindinių skaitliukų (metodo iteracijų skaičių, funkcijos kvietimo kiekį, intereso taškų - rekursyviai perduodamos x vertės algoritmo veikimui).
Klasės pagrindinis tikslas- būti paveldėta algoritmui specifinių klasių.

IntervaloDalijimasPusiau, AuksinioPjuvio, Niutono- klasės atitinkamai pagal savo pavadinimą atlieka nusakytą algoritmą, paveldi Function klasę, skaičiuoja iteracijas, funkcijų kvietimus, minimumą funkcijos. SVARBU- Niutono metodo išvestinės randamos analitiškai.

Projekto tikslas- pademonstruoti 3 algoritmų veikimą ir gauti informacijos pilnaverčiui palygnimui.
